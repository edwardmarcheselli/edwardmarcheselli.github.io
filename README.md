# Edward A. Marcheselli Portfolio

A static, responsive portfolio showcasing my work in engineering software leadership, embedded systems, real-time simulation, and technical web applications.

I designed this site for GitHub Pages, with no build step or backend. Open `index.html` locally for a preview, or publish the repository through GitHub Pages.

## Structure

- `index.html`: portfolio content and semantic structure
- `styles.css`: responsive visual system and layout
- `main.js`: navigation, section state, and progressive reveal behavior
- `images/`: project screenshots and static media

My featured repositories include the CAD Workspace TypeScript/React demo and the NXT autonomous robot controller.
